# FMcos 钱包工具箱 v1.4.5（自定义扫描 / 随时停止版）

## v1.4.5 新功能（本轮需求）

### 1. 自定义扫描（自定义文件目录/ID）
扫描方式菜单新增第三项「**自定义扫描（输入目录/文件 ID，支持区间如 2F00-2FFF）**」：
- 输入格式：2 字节 HEX 的 FID，支持三种写法混用，逗号/空格/分号分隔：
  - 单个 ID：`3F01`、`AD01`
  - 区间：`2F00-2FFF`（防误输入上限 4096 个 ID）
  - 组合：`3F00, 3F01, 2F00-2FFF, AD01`
- 扫描行为：先回到 MF，再逐个 ID 用 `SELECT by FID`（自动 P2=0C 按名优先、失败回退 P2=00）探测，命中的列出 FID + FCI 前 32 字节
- 适用：已知某些特定 FID/FID 段，快速定点探测，不用等全扫描

### 2. 随时停止扫描
- **任何扫描（智能/全扫/自定义）进行中**，原「选择扫描方式」按钮自动变为「**停止扫描**」
- 点击立即置停止标志，扫描循环在下一个检查点中断（通常 &lt;1 秒，卡操作间隙即停）
- 已扫到的结果保留显示，状态栏提示"已停止（保留已扫到的部分）"，按钮恢复为"选择扫描方式"
- 注：若正处于一次 APDU 传输中，最多等该次超时（3 秒）后停

## 使用提示
- 自定义扫描同样需要主页先贴卡连接
- 区间过大（>4096）会提示格式错误；输入非法 HEX 同样提示
- 结果区命中的 FCI 字节可用于后续手工构造命令参考

# FMcos 钱包工具箱 v1.4.4（真卡 PIN 修复 / GP 连接互通版）

## v1.4.4 修复（本轮反馈）

| 反馈问题 | 根因 | 修复 |
|---|---|---|
| 真卡 PIN 认证失败（63CE） | v1.4.3 主页 verifyPin 改成 ASCII 发送（6 字节 313233343535），但**真 FMCOS 卡规范是 hex 压缩 PIN**（"123455"→3 字节 12 34 55，原版 APP 即如此设计）；ASCII 尝试被真卡按"错误 PIN"计次 | 主页 verifyPin 恢复 **hex 优先**：合法 hex 字符串（偶长、全 hex 字符）按 hex 编码发送；非法 hex（如含字母以外的奇数长度 PIN）自动回退 ASCII。applet v2.3 双格式均接受，互不影响。预设命令同步改回 `00 20 00 00 03 123455` |
| 剩余次数显示"206次" | `63CE` 的 SW2=0xCE，APP 取整个字节（206）显示，未取低 4 位 | 修正为 `SW2 & 0x0F`：63CE → 剩余 **14** 次 |
| 切 GP 仍需重连 | GP 页(GPDroid)的已连接 UI 状态只在贴卡事件（serviceConnected）后刷新；切页后无事件 → 显示未连接，用户被迫重贴卡 | GP 页 onResume 注入 GpNfcPatch：terminal.isConnected()（已带主页会话采纳）为真时立即驱动 serviceConnected → **切页即已连接**，免重贴卡 |
| GP 页贴卡弹回主页 | GPDroid 用 `createPendingResult(1,intent,0)` 注册前台派发、贴卡经 onActivityResult 接收——该通道在新系统上不可靠；派发失效时贴卡被 manifest 兜底过滤器（AppletSettingsActivity 的 TECH_DISCOVERED intent-filter）或主页派发劫持，弹到其他页面且 GP 不连接 | 三管齐下：① GP 主页新增 **onNewIntent** 处理 TECH_DISCOVERED（复用原 tag 处理逻辑：passTag→isConnected→serviceConnected）；② GpNfcPatch 用**标准 PendingIntent**（显式组件+SINGLE_TOP，与 PBOC 主页同款、已在真机验证）重注册前台派发；③ 移除 AppletSettings 的 manifest TECH 过滤器（无对应处理代码，纯劫持源） |
| GP 页贴过卡回主页也要重贴 | 会话互通此前只有单向（主页→GP） | 主页 onResume 注入**反向采纳**：主页 isoDep 失效而 GP terminal 仍持有活动会话时，自动接管（需引擎已初始化，避免误触） |

## 使用要点

### PIN（四方默认 123455）
- **主页（对真卡）**：`00 20 00 00 03 + 12 34 55`（hex 压缩，FMCOS 规范）；PIN 输入框直接输数字即可，偶数位全数字按 hex 编码
- **钱包页/设置页（对本 applet）**：ASCII 明文；applet v2.3 两种格式都接受
- 连错 3 次锁卡（63C2→63C1→63C0，显示真实剩余次数），锁死后 6983；设置页改 PIN 下发（80DC）自动解锁
- ⚠️ 真卡 PIN 每次失败都会消耗卡内计数（63CE=剩 14 次），请确认卡的真实 PIN

### GP/PBOC 切换（双向免重贴）
- 主页连着卡 → 切 GP：GP 页进入即已连接，命令直接执行
- GP 页重新贴卡 → 回主页：自动接管 GP 会话
- GP 页贴卡不再弹回其他页面（标准派发 + onNewIntent 接收）
